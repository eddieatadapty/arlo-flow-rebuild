# Arlo Growth Audit

**Live → https://eddieatadapty.github.io/arlo-flow-rebuild/**

Five ideas to turn more Arlo users into subscribers, each built into a clickable version of Arlo's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask what Arlo should watch for, then use the answer | +10–20% CR to purchase |
| 02 | Show a smart alert before the price | +10–15% CR to purchase |
| 03 | Sell the plan in the app, the day the free month starts | +10–20% CR to purchase |
| 04 | Price by the cameras they own, and make the year add up | +10–15% ARPU |
| 05 | Put your proof where they decide | +10–15% CR to purchase |

Every price, rating and feature comes from Arlo's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Arlo. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
